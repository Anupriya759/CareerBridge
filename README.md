# CareerBridge Job Portal 

A lightweight frontend-only college project with working navigation, job search/filtering, save jobs, company pages, login/register demo, profile storage, and salary analytics.

## Run

1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. For best results, use the VS Code Live Server extension and open `index.html`.

## Important
This is a frontend-only version. Data is stored in the browser's localStorage. It does not connect to MySQL/Spring Boot yet.

## Pages
- Home
- Jobs + search/filter/sort
- Job details
- Companies + company details
- Login/Register demo
- Profile
- Saved Jobs
- Salary Analytics
- About
- Contact

## Demo login
Create an account on Register first. The details are saved in this browser, then use the same email/password on Login.
